# v0.8.1 — 2026-11-01

This release organizes the project for open-source development and distribution. The public CLI remains `desktop-agent-bridge`.

- Group production sources under `src/`, Windows and Python helpers under `scripts/`, offline tests under `tests/`, and baseline manifests under `compat/baselines/`.
- Preserve immutable, self-contained native adapter snapshots through a logical source map. Existing verified profile IDs and native helper bytes remain unchanged.
- Make English the default README, retain the Chinese translation, and add contribution guidance and a documentation index.
- Update installation, supervision, MCP configuration, dependency checks, and npm contents for the new layout. Exclude local runtime state, credentials, tests, and Python caches from distribution.

Validation includes 93 Node tests, 15 Python tests, source/profile digest checks, PowerShell syntax checks, a clean checkout export, and isolated package installation. Passive desktop diagnosis does not attach native helpers or create runtime state.

After npm publication, registry integrity and an actual registry installation are verified before creating the tag and [GitHub Release](https://github.com/neeetman/desktop-agent-bridge/releases/tag/v0.8.1). The GitHub Release records the published source commit and final verification evidence.

```powershell
npm install -g @neeetman/desktop-agent-bridge@0.8.1
```

Package installation does not configure MCP or start desktop applications. Keep an existing live installation in place until an idle maintenance window; do not overwrite a global installation while its services are running. A live helper upgrade, a second-machine cold install, and a full Windows reboot retain the validation gaps described in [validation scope](../validation.md).
